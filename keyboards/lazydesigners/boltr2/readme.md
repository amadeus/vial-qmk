# Bolt R2

A 40% ergo keyboard designed and produced in 2025–2026 by [LAZYDESIGNERS](http://lazydesigners.cn).

* Keyboard Maintainer: [LAZYDESIGNERS](https://github.com/jackytrabbit)
* Hardware Supported: Bolt R2 (2026 group buy)
* Hardware Availability: Check [LAZYDESIGNERS's homepage.](http://lazydesigners.cn)

Make example for this keyboard (after setting up your build environment):

    make lazydesigners/boltr2:default

Flashing example for this keyboard:

    make lazydesigners/boltr2:default:flash

To build or flash the Vial firmware, replace `default` with `vial`.

**Reset:** Hold the BOOT button and tap RESET to enter the bootloader.
